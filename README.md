# house-template-dotnet-ai

The AI add-on for the .NET layer of my Copier project templates: Microsoft Agent Framework agents on [house-template-dotnet](https://github.com/olaheavy-dev/house-template-dotnet), with cost-capped model calls (Claude, OpenAI or Foundry), RAG on Postgres, an MCP server and client, two levels of evaluation and tracing.

Built through reviewed pull requests; the design is in the House template plan (".NET layers").
